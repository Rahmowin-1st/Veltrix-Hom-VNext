# Global Search

Global search returns typed deduplicated scored results: type, id, title, snippet, optional Project ID, score and deep link. Android consumes `SearchResultModel`.

Coverage includes Projects, conversations/message text, Sources, notes, assessments/tests/quizzes, flashcards, mistakes, goals, practice, achievements, Map units, inventory and Store where applicable. Account ownership is mandatory; Project filters only narrow. Source search adds hybrid lexical/semantic retrieval. Tenant filtering is applied before AI/model use.
