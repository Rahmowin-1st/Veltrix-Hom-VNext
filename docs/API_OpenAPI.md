# API / OpenAPI

`contracts/openapi.yaml` is OpenAPI 3.1. `scripts/generate_openapi_contract.py` derives the public `/v1` inventory from Ktor registration and `scripts/verify_openapi_drift.py` fails on undocumented or stale operations. Current completion source targets 106 public v1 operations with unique operation IDs. Android consumes repository/domain contracts rather than raw SQL.
