# Home Snapshot v3

`GET /home` returns one bounded aggregate: identity/avatar, effective/xp levels, lifetime/current/next/remaining XP, Coins, qualified active days, consistency, current/recent Projects, recent assessment/review topics/Sources, quick-action eligibility, memory maturity, Map state/current unit, season, achievement/unread indicators, sync state, deterministic priorities/insights, world continuity IDs, revision, generatedAt and schemaVersion 3.

It is a read model for startup efficiency; ledgers/entities remain authoritative in their domains.
