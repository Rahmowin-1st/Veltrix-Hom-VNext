# AI Context Pipeline

Chat resolves conversation scope, explicit Project, active Project instruction, Learning Mode, selected Sources and READY attachments, account Memory, matching Project Memory, hybrid evidence and allowed deterministic tools. `ContextPlanner` applies scope/ownership rules; `PromptPolicyComposer` separates policy from user content. Assistant segments and real citation mappings are persisted, then post-response jobs are queued off the visible streaming path.
