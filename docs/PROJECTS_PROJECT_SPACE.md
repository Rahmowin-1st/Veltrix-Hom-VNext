# Projects / Project Space

Project Space scopes goals, chats, sources, notes, assessments, flashcards, mistakes, practice, instructions, customization, recommendations and ContextCarry.

`GET /projects/{id}/workspace` returns Project Workspace v3: Project, goals, recent chats, source/note/assessment/flashcard/mistake/practice counts, Project memory signal count, meaningful-event count, active instruction, recommendations, ContextCarry, world continuity IDs, revision and schemaVersion 3.

Every operation checks account ownership. Customization stores semantic fields/order/policies, not final visual design.
