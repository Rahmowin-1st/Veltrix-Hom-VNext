# Observability — Final

Operational truth uses health/readiness, structured server logs, typed errors, durable job/lifecycle state and explicit CI evidence. Source processing, deletion, sync and provider boundaries expose persistent state instead of invisible in-memory completion.

The final package carries readiness/log output, migrations, HTTP smoke, Android runtime/process-death, security/red-team and hash/provenance evidence. Production metrics/traces/SLO dashboards remain deployment concerns and are not claimed without execution.
