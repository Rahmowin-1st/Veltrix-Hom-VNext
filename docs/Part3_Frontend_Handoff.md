# Part 3 Frontend Handoff

Frontend may replace all developer-shell presentation without rewriting business logic. Primary destinations: HOME, PERSONAL, STORE, PROJECTS. Capability destinations: CHAT, LIBRARY, TESTING, PRACTICE, QUIZZES, FLASHCARDS, MISTAKES, CALCULATOR, TRANSLATE, NOTIFICATIONS, SETTINGS. Repositories expose loading/success/empty/error/offline/processing/conflict/retry state; frontend never calls raw SQL.
