# Part 2 Integration Contract

Part 1 emits meaningful idempotent activity events such as PROJECT_CREATED, GOAL_COMPLETED, SOURCE_ADDED, TEST_COMPLETED, QUIZ_COMPLETED, PRACTICE_COMPLETED, FLASHCARD_REVIEW_COMPLETED, MISTAKE_RESOLVED, NOTE_CREATED and MEANINGFUL_CHAT_SESSION. Part 2 may consume them for Level/XP/Coins/Map/Seasons/Store/achievements without changing learning engines. Part 1 does not award XP or implement economy.
