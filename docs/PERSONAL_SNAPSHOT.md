# Personal Snapshot v3

`GET /personal` returns account identity/language/timezone/avatar, effective/xp level, lifetime XP, Coins, qualified days, Student Model summary, strengths/weaknesses/interests/goals, active Project/completed assessment/due flashcard/active mistake counts, Map/season, achievements/inventory, consistency, recent activity, world continuity IDs, revision, generatedAt and schemaVersion 3.

This is a bounded presentation read model, not client authority over derived totals.
