# Personal Map — Final

The default final season defines 10 units. Unit stage order is MISSION → PRACTICE → CHALLENGE → FINAL_CHECK. Eligibility combines progression/memory/qualified-state rules; future units cannot be client-unlocked out of sequence.

Checkpoint rewards are deterministic: every 5 units can award the Noob checkpoint and every 20 the Pro checkpoint; a 20-unit checkpoint does not also count as Noob. Map/reward policy lives in core/DB, never AI/client.
