# Project Brain

Project Brain is the scoped continuity/context layer combining active Project instruction, Project Student Model evidence, linked Sources, goals/recent chats, recommendations, ContextCarry and bounded workspace counts.

Project AI context may use global account evidence plus same-Project evidence, never another Project's private context. Instructions are explicit/versioned durable state. World continuity IDs keep account/avatar/progression/project/map/season references stable across surfaces.
