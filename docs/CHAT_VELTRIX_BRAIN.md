# Chat / Veltrix Brain

Chat persists conversations/messages, attachments, citations, edit branches, regenerate/retry actions, Project links and save-note flows. Chat is an application surface, not product authority.

Veltrix Brain context uses explicit conversation scope, Project instruction, authorized Sources, ContextCarry and eligible Student Model evidence. Citation endpoints bind responses to retrieved source evidence; fabricated citation IDs are not provenance.

Chat may emit meaningful activity/memory candidates but cannot mint XP/Coins or cross account/Project boundaries. Provider outage degrades AI only; durable product state remains accessible.
